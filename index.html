zenwriter-mode

Distraction-free writing for Emacs, inspired by iA Writer.

Light Dark
  • Light and dark themes — auto-detected from system appearance
  • Olivetti centering, generous line spacing, hidden chrome
  • Focus mode — dims all text except the current line
  • First-class Org and Markdown faces
  • One command to enable, one to restore

Quick start

;; Load the theme only
(load-theme 'zenwriter t)

;; Full experience — theme, font, hidden chrome
(global-zenwriter-mode 1)

Install

(use-package zenwriter-mode
  :straight (zenwriter-mode
    :type git
    :host github
    :repo "jhou1/zenwriter-mode"
    :files ("*.el"))
  :commands (zenwriter-mode global-zenwriter-mode)
  :init
  (add-to-list 'custom-theme-load-path
    (expand-file-name "straight/repos/zenwriter-mode"
                      user-emacs-directory)))

Customize

(setq zenwriter-font-family "Iosevka")
(setq zenwriter-body-width 90)
(setq zenwriter-line-spacing 6)
